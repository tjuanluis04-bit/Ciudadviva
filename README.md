# Ciudad Viva

1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. Ve a **Actions → Build APK** (se ejecuta solo con cada push, o con *Run workflow*).
3. Al terminar, descarga el artefacto **ciudad-viva-apk** y abre `app-debug.apk` en tu Android.

Probar en el navegador: abre `www/index.html`.
